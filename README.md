# Library Management System in C

## 📌 Project Overview

This project is a console-based **Library Management System** developed in the C programming language as part of the **Algorithmique et Structures de Données 1 (ASD1)** course.

The application allows users to manage books, members' loans, returns, and generate useful statistics through an interactive menu-driven interface.

## 🚀 Features

### 📚 Library Management

* Display the list of books
* Add a new book
* Delete a book
* Modify the number of available copies
* Search for a book by title
* Display available books

### 📖 Loan Management

* Register a new loan
* View a member's loans
* Register book returns
* Display active loans
* Identify overdue loans
* Display loans according to their expected return date
* Delete loans within a specified date interval

### 📊 Statistics

* Calculate the total number of books
* Calculate the total number of members
* Calculate the total number of loans
* Find the most borrowed books
* Identify books that have never been borrowed
* Find the most borrowed books within a specific period
* Identify the most frequent borrowers

## 🛠️ Technologies & Concepts

* **C Programming**
* Arrays
* Matrices
* Functions
* Modular programming
* String manipulation
* Input validation
* Date validation and comparison
* Searching and counting algorithms
* Console-based user interface
